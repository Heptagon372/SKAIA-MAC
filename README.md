# SKAIA Studio for Mac

내 PC에서 돌아가는 로컬 AI 앱 SKAIA Studio의 Mac 다운로드 페이지입니다. 이 저장소에는 설치 파일만 있습니다.

**[다운로드 (SKAIA-Studio-Mac-arm64.dmg)](https://github.com/Heptagon372/SKAIA-MAC/releases/latest/download/SKAIA-Studio-Mac-arm64.dmg)**

- Apple 칩(M1 이후) Mac, macOS 12 이상
- 무료, 계정 필요 없음

## 설치

1. DMG 파일을 열고 SKAIA Studio를 응용 프로그램(Applications) 폴더로 끌어다 놓습니다.
2. 앱을 처음 열면 Mac이 막습니다. Apple 개발자 서명이 아직 없기 때문입니다.
3. 시스템 설정 › 개인정보 보호 및 보안으로 가서 아래쪽의 「그래도 열기」를 누릅니다.

## 알아 두기

- 시험판입니다. Mac용 빌드는 자동 테스트를 통과했지만, 실제 Mac에서 화면을 확인하기 전입니다.
- AI는 CPU로 돌아갑니다. GPU 가속(Metal)은 아직 켜지 않았습니다.
- 앱 안에서는 업데이트되지 않습니다. 새 버전은 이 페이지에서 DMG를 다시 받으세요.
- 학습 스튜디오는 Mac에서 아직 시험하지 않았습니다.

받은 파일 확인: 릴리스의 `SHA256SUMS.txt`와 `shasum -a 256 SKAIA-Studio-Mac-arm64.dmg` 결과를 비교하세요.
